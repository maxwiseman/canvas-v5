## v0.6.0

- Index Canvas Page titles and full bodies alongside assignments in site search, including courses where Canvas disables the Pages navigation tab; linked assignments, Pages, quizzes, discussions, announcements, and files now flow through the same normalization pipeline as enumerated API records, and Pages are available through the MCP server.
- Render crawled Pages instantly during in-course navigation from the normalized resource cache, and remove the obsolete Pages object store through a coordinated IndexedDB upgrade that lets other open Canvas tabs release their database connections.
- Add compact previous and next Page actions to the header and prefetch adjacent module sequence data so both header and footer controls stay responsive while moving between cached Pages.
