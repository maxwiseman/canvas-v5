## v0.9.0

- Show the grade (score, points possible, and letter/display grade) on the assignment detail page, matching the grades page.
- Rename Canvas submission comments to Feedback on the assignment detail page and show comment attachments.
- Automatically save text submission drafts to Canvas’s native draft storage and an account-scoped local IndexedDB store. Restore rich text when returning to an assignment, retry pending saves after reconnecting, and show save status and choices when Canvas contains a conflicting draft.
- Preserve image descriptions, Canvas attachment references, and code formatting when restoring drafts; clear the completed local draft after submission.
- Show the Canvas-computed weighted course total (current score with letter grade, plus final score counting ungraded as zero) on the grades page instead of a naive points average. Falls back to a labeled estimate when Canvas has not returned a total yet.
- Open text submissions in a spacious rich-text editor with formatting, colors, lists, links, and a word count; keep drafts when closing the editor or retrying a failed submission.
- Keep submission-type tabs with icons and labels, automatically showing icons with tooltips when the labels do not fit.
- Add compact file-upload submissions with file-type validation, upload status, and retry support; replace the unlabeled fallback with explicit Canvas actions for media, annotation, quizzes, discussions, and external tools.
- Replace the inset submission editor card with a full-height writing surface and a shadcn text-style selector.
- Add compact text-color and highlight popovers with a saturation/hue picker, presets, hex input, and reset controls.
- Support inline code, code blocks, and images inserted by URL or uploaded to Canvas, preserving code whitespace and image references in submitted HTML.
- Show submission-type tooltips only when the tabs display icons without text labels.
